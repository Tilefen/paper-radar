I. INTRODUCTION

甲醛三聚体，即1,3,5-三噁烷或(H 2CO)3，属于聚甲醛（POM）类分子，被认为与生命起源前化学高度相关，可作为彗发中甲醛的来源1,2。然而，迄今尚未报道对POMs的确凿天文探测。1,3,5-三噁烷因其原子数相对较多且质量较高而具有密集的转动光谱，可作为合适的射电天文示踪物。凭借其丰富的微波、THz和中红外（IR）光谱，三噁烷也是一种有前景的分子，可用于实现光泵浦远红外气体激光器3（近来人们对这类激光器重新产生了兴趣4,5），并利用其几乎连-进行频率校准与计量。

II. EXPERIMENTAL DETAILS

V. DISCUSSION

根据上述，仅约 110 个中红外谱线位置——利用亚多普勒激光光谱以创纪录的几十 kHz 不确定度确定——就使我们能够确定分子参数，其不确定度相比 FT 光谱在 6 MHz 内已知的约 2500 个频率所达到的水平改善了 3 至 30 倍。然而，我们的工作表明，要获得最精确的一组分子参数，这两个数据集都是必需的。饱和吸收数据不仅对于达到最高精度至关重要，而且更实际地，对于进行 FT 数据的后验频率校准也是不可或缺的，而后者是我们所建立流程的组成部分，没有它——

联合分析就不可能实现。相反，利用源自 FTIR 分析的 Set 2 参数获得的频率位置，对于首先实现对饱和吸收光谱的指认、进而对其加以利用也至关重要。此外，如果由于 FT 光谱仪的校准不完善，Set 2 与 Set 3 参数在很大程度上不相容，那么即使在后期校准之后，Set 3 与 Set 4 中的参数虽然一致得多，但在其误差棒内也并非完全相容。我们的超精密亚多普勒测量的光谱覆盖范围仅允许探测 P 和 Q 支中的跃迁，我们认为这会导致在——

分子参数的确定。事实上，我们先前对ν5基频带的亚多普勒研究仅依赖于来自QCL光谱仪数据的47条已归属P支谱线（见补充材料表S4），得到的参数偏差甚至更大（此外不确定度还要大一到两个数量级）14。用提供数千条谱线的高分辨率傅里叶变换（HR FT）研究来补充我们完整的计量级数据集，这些谱线适当地采样了从低K和J到高K和J的整个P、Q和R振动范围，这是避免偏差的关键。这解释了Set 3与Set 4之间的轻微不一致。两组显示出相似的不确定度——Set 4对四阶和六阶常数的不确定度略好——
